# MacCare Local 0.7.1 (prerelease) — Compliance Hardening

Internal audit-and-package repair pass on top of 0.7.0. No new user-facing
features; hardening and correctness only:

- SafetyCore's audit log is now persisted to SQLite (append-only), not just
  in-memory.
- Quarantine records richer metadata (permissions, size, hash, volume) and
  never silently overwrites an existing file on restore.
- ClamAV scanning gained a configurable timeout, real cancellation, and an
  honest scanned-file count.
- Privacy Cleaner now disables cleaning per browser profile while that
  browser is running, with a close-and-rescan action.
- Accessibility: Increase Contrast, Differentiate Without Color, and
  labels/grouping added across previously-unannotated views.
- CI split into an always-green normal path and a separate manual
  publish-readiness gate; two real CI bugs fixed.

**Pre-1.0 releases are currently distributed without a Developer ID
signature and without Apple notarization.** Same known limitations as
0.7.0 (see Documentation/KNOWN_LIMITATIONS.md) — not a public GitHub
release yet.
