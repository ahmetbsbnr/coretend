# CoreTend 1.0.0

The first stable CoreTend release. It is functionally the 0.9.1-rc.6 line,
promoted to 1.0 now that signing, notarization and the full automatable
release-readiness gate are all in place. rc.6 remains unchanged in the release
history.

## Signed and notarized

The app and the disk image are both **Developer ID Application** signed
(Team NSCUV5G738) and Apple **notarized**, with the ticket stapled — Gatekeeper
opens them with no "unidentified developer" prompt and no network round-trip at
first launch. Copy CoreTend to `/Applications` and open it; nothing else is
required. Never disable Gatekeeper globally or remove quarantine recursively.

Hardened Runtime is enabled with a minimal entitlement set (no App Sandbox —
CoreTend inspects files wherever the user points it; no `com.apple.security.cs.*`
exceptions). CoreTend is not available from the Mac App Store; an App Store
edition remains a separate study.

## What CoreTend does

Local, transparent and reversible macOS care. Scanning is read-only. Cleanup,
Duplicates, Applications, Leftovers, Privacy Cleaner and Space Lens each show
the reviewed selection and require an explicit confirmation before eligible
items move to the macOS Trash. SafetyCore re-validates every approved path
immediately before execution, protects system roots and rejects symlink
escapes. IntegrityCore is the read-only integrity implementation — download
provenance, code-signature tiers and login items; it is not an antivirus.

The only product network request is a user-initiated update check for the
public `latest.json` manifest, and it never downloads or installs anything.

## Changes since rc.6

- The standalone Smart Care orchestrator was retired; its landing is the
  Dashboard (free space, Trash state, exclusions, recent activity, a large
  scan action, shortcuts into the other modules).
- Crash / robustness matrix items 25 (disk nearly full), 27 (CPU under load)
  and 38 (update-check timeout) are now covered by real automated tests.
- Version 1.0.0, build 1000, channel `stable`.

## Verify

```
xcrun stapler validate CoreTend-1.0.0-arm64.dmg
spctl --assess --type open --context context:primary-signature --verbose CoreTend-1.0.0-arm64.dmg
shasum -a 256 -c SHA256SUMS
minisign -Vm SHA256SUMS -P <public key from Configuration/minisign.pub>
```
