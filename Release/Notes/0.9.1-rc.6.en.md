# CoreTend 0.9.1-rc.6 (release candidate)

This release candidate supersedes 0.9.1-rc.5. It is not a stable 1.0, and
rc.5 remains unchanged in the release history.

## Signed and notarized

This is the first CoreTend build distributed with a real **Developer ID
Application** signature (Team NSCUV5G738) and Apple **notarization**. The app
and the disk image are both notarized and stapled, so Gatekeeper opens them
without the "unidentified developer" prompt and without any network round-trip
at first launch. Copy CoreTend to `/Applications` and open it — nothing else
is required. Never disable Gatekeeper globally or remove quarantine
recursively.

Hardened Runtime is enabled with the same minimal entitlement set as before
(no App Sandbox — CoreTend inspects files anywhere the user points it; no
`com.apple.security.cs.*` exceptions). CoreTend is not available from the Mac
App Store; an App Store edition remains only a future study.

## Also in this build

Functionally identical to rc.5. Scanning stays read-only; Cleanup, Smart Care,
Duplicates, Applications, Leftovers, Privacy Cleaner and Space Lens show the
reviewed selection and require explicit confirmation before eligible items move
to the macOS Trash. SafetyCore re-validates every approved path immediately
before execution, protects system roots and rejects symlink escapes.

IntegrityCore remains the current read-only integrity implementation. The
retired ClamAV interface, process wrapper and scanner are not present.

## Verify

```
xcrun stapler validate CoreTend-0.9.1-rc.6-arm64.dmg
spctl --assess --type open --context context:primary-signature --verbose CoreTend-0.9.1-rc.6-arm64.dmg
shasum -a 256 -c SHA256SUMS
minisign -Vm SHA256SUMS -P <public key from Configuration/minisign.pub>
```
