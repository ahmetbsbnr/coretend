# MacCare Local 0.7.0 (préversion)

MacCare Local est un utilitaire macOS open source conçu pour analyser,
nettoyer, organiser et optimiser les Mac Apple Silicon. Il fonctionne
entièrement en local, sans compte, sans abonnement et sans télémétrie.
Chaque élément détecté est expliqué avant toute action, et les
suppressions utilisent par défaut la Corbeille afin de rester
réversibles.

**Les versions pré-1.0 sont actuellement distribuées sans signature
Developer ID et sans notarisation Apple. Le code source, les sommes de
contrôle et les détails de chaque version sont publics.**

Cette version est un instantané de travail en cours, pas une publication
GitHub publique — voir « Limitations connues » ci-dessous.

## Changements depuis la 0.6.0

La 0.6.0 a livré la fondation open source (licence, docs, CI, scripts
publics, fondation du site bilingue). Ce cycle 0.7.0 ajoute
l'empaquetage de distribution publique pour lequel cette fondation avait
été construite :

- **Audit de compatibilité** (`Documentation/COMPATIBILITY.md`,
  `API_AVAILABILITY_AUDIT.md`, `SUPPORTED_MACS.md`,
  `MACOS_VERSION_POLICY.md`) : chaque API utilisée a été vérifiée par
  rapport à la cible de déploiement macOS 14.0, en examinant chaque
  import et symbole SwiftUI/Observation. `@Observable` (16 fichiers) est
  la contrainte déterminante ; rien au-dessus du seuil 14.0 n'est
  utilisé. Aucune protection `@available` n'a été nécessaire.
- **Artefact ZIP non signé** (`Scripts/package-zip.sh`) : arm64
  uniquement, signature ad-hoc, licences incluses, aucune donnée locale
  du dépôt. Vérifié en extrayant vers un chemin indépendant et en
  confirmant que l'app se lance, que les ressources/la localisation se
  chargent, et qu'elle se ferme proprement.
- **Artefact DMG non signé** (`Scripts/package-dmg.sh`) : DMG simple et
  fonctionnel avec le `.app`, un raccourci `/Applications`, et les
  licences. Vérifié avec un cycle complet montage → copie → éjection →
  lancement.
- **Sommes de contrôle** : `Release/SHA256SUMS` couvre le ZIP, le DMG et
  le manifeste de version. `Scripts/verify-download.sh <fichier>
  <sha256>` vérifie via `shasum -a 256` sans jamais exécuter le fichier.
- **Manifeste de version** : `Release/latest.json`.

## Compatibilité

- Apple Silicon (arm64) uniquement.
- macOS 14.0 (Sonoma) ou ultérieur.
- Construit et testé sur un seul Mac physique (macOS 26.5.1, arm64).
  Aucune autre machine ni version d'OS n'était disponible pour vérifier
  — voir `Documentation/API_AVAILABILITY_AUDIT.md` pour le détail exact
  de cette limite.

## Installation

Voir `Documentation/INSTALL_UNSIGNED.md` pour la marche à suivre
complète (téléchargement → vérification de la somme de contrôle →
ouverture du DMG/extraction du ZIP → copie vers Applications →
autorisation dans Réglages Système > Confidentialité et sécurité si
Gatekeeper bloque le premier lancement). L'accès complet au disque est
requis pour la plupart des fonctions d'analyse ; ne l'accordez que
lorsque demandé, uniquement pour cette app.

L'intégration ClamAV (module Protection) est optionnelle — MacCare
Local n'intègre ni ClamAV ni sa base de signatures virales ; voir
`CLAMAV.md`.

## Limitations connues

- Non signé, non notarié : Gatekeeper bloquera le premier lancement
  jusqu'à autorisation explicite.
- Vérifié sur un seul Mac physique ; aucun test multi-matériel ou
  multi-version d'OS n'a été effectué ce cycle.
- Aucune publication GitHub publique n'existe encore — il n'y a pas
  d'URL de téléchargement publique. Ce manifeste et ces artefacts sont
  une sortie de build locale, documentée et vérifiée par somme de
  contrôle de la même manière qu'une vraie publication le serait.
- Le chantier complet de distribution (script de désinstallation
  peaufiné, diagnostics intégrés, tests spécifiques à la distribution,
  job CI d'empaquetage, page de téléchargement du site) n'est pas
  terminé — voir `Documentation/CHANGELOG.md` pour le détail exact de ce
  qui a été livré ce cycle et de ce qu'il reste à faire.

Vérification manuelle avec :

shasum -a 256 "MacCare-Local-0.7.0-arm64-unsigned.zip"
