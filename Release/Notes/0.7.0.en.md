# MacCare Local 0.7.0 (prerelease)

MacCare Local is an open source macOS utility to analyze, clean,
organize, and optimize Apple Silicon Macs. It runs entirely locally — no
account, no subscription, no telemetry. Every detected item is explained
before any action, and deletions use the Trash by default so they stay
reversible.

**Pre-1.0 releases are currently distributed without a Developer ID
signature and without Apple notarization. The source code, checksums,
and details of every version are public.**

This build is a work-in-progress snapshot, not a public GitHub release —
see "Known limitations" below.

## What changed since 0.6.0

0.6.0 shipped the open source foundation (license, docs, CI, public
scripts, bilingual website foundation). This 0.7.0 development cycle
adds the actual public-distribution packaging that foundation was built
for:

- **Compatibility audit** (`Documentation/COMPATIBILITY.md`,
  `API_AVAILABILITY_AUDIT.md`, `SUPPORTED_MACS.md`,
  `MACOS_VERSION_POLICY.md`): verified every API used against the macOS
  14.0 deployment target by grepping every import and SwiftUI/Observation
  symbol. `@Observable` (16 files) is the binding constraint; nothing
  above the 14.0 floor is used. No `@available` guards were needed.
- **Unsigned ZIP artifact** (`Scripts/package-zip.sh`): arm64-only,
  ad-hoc signed, licenses bundled, no repo-local user data. Verified by
  extracting to an unrelated path and confirming the app launches,
  resources/localization load, and it quits cleanly.
- **Unsigned DMG artifact** (`Scripts/package-dmg.sh`): plain functional
  DMG with the `.app`, an `/Applications` shortcut, and licenses.
  Verified with a full mount → copy → eject → launch round-trip.
- **Checksums**: `Release/SHA256SUMS` covers the ZIP, DMG, and release
  manifest. `Scripts/verify-download.sh <file> <sha256>` verifies via
  `shasum -a 256` without ever executing the file.
- **Release manifest**: `Release/latest.json`.

## Compatibility

- Apple Silicon (arm64) only.
- macOS 14.0 (Sonoma) or later.
- Built and tested on a single physical Mac (macOS 26.5.1, arm64). No
  second machine or OS version was available to verify on — see
  `Documentation/API_AVAILABILITY_AUDIT.md` for exactly what that gap
  means.

## Installation

See `Documentation/INSTALL_UNSIGNED.md` for the full walkthrough
(download → verify checksum → open DMG/extract ZIP → copy to
Applications → allow in System Settings > Privacy & Security if
Gatekeeper blocks the first launch). Full Disk Access is required for
most scan features; grant it only when prompted, only for this app.

ClamAV integration (Protection module) is optional — MacCare Local does
not bundle ClamAV or its virus database; see `CLAMAV.md`.

## Known limitations

- Unsigned, not notarized: macOS Gatekeeper will block the first launch
  until you explicitly allow it.
- Verified on one physical Mac only; no multi-hardware or multi-OS-version
  testing was performed this cycle.
- No public GitHub release exists yet — there is no public download URL.
  This manifest and these artifacts are local build output, documented
  and checksummed the same way a real release would be.
- The full distribution gate (uninstall script polish, in-app diagnostics,
  distribution-specific tests, CI packaging job, website download page)
  is not complete — see `Documentation/CHANGELOG.md` for exactly what
  landed this cycle versus what remains.
