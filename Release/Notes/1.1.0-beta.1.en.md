# CoreTend 1.1.0-beta.1 (beta)

The first public beta of the 1.1 line. It is **not** a stable release. The
published stable version remains **1.0.0**, and this beta does not replace it:
the in-app updater will not offer 1.1.0-beta.1 to anyone on the default
`stable` channel.

Version 1.1.0-beta.1, build 1100, channel `beta`, prerelease.

## Highlights

- **Smart Scan** (*Analyse intelligente*) — one action on the Dashboard runs
  several CoreTend modules and returns a single structured review: what is
  potentially recoverable, what needs a look, what to be aware of, and what is
  informational only, kept as four separate dimensions. Elapsed time is shown;
  there is no fabricated percentage. Nothing is deleted by the scan.
- **Space Lens 2.0** — an interactive size map of any folder you point it at,
  with progressive partial results while it scans, a treemap and list that
  stay in sync, breadcrumb and back navigation, an *Other* bucket, search and
  category filtering. Analysis only — nothing is modified.
- **Recovery Plan** (first vertical) — pick a space goal; CoreTend proposes a
  conservative, fully user-editable plan from eligible findings across
  Cleanup, Duplicates, Leftovers and Privacy, then executes only what you
  confirm, one source at a time, through the same validated Trash path the
  individual modules use.
- **Restore Center** — move items CoreTend put in the Trash back to exactly
  where they came from, while they are still in the Trash and the original
  location is free. A name collision is refused, never overwritten.
- **Storage Timeline** (first vertical) — "since last scan" changes for
  Cleanup, Duplicates, Leftovers and Privacy, plus a Dashboard summary card.
- **Truthful Storage semantics** — the scan/review/selected/recovered states
  stay visually distinct, live progress is real, and the confirm bar always
  shows the amount you have selected.
- **Advisor** — per-finding risk, confidence, reversibility and size context
  on review rows.
- **Developer Center** (first vertical) — Xcode and package-manager caches
  (SwiftPM, Homebrew, npm, pnpm, Yarn), plus read-only CoreSimulator and
  Docker views. Simulator and Docker cleanup are out of scope.
- **Applications** — inventory, associated data, Trash-based uninstall, and
  conservative Leftovers matching with shared/ambiguous detection.
- **Privacy Lab** — read-only inspection of an image's metadata (location,
  capture date, camera, software, author, and more) reported as
  Present / Not detected / Unavailable, never "safe". It never modifies your
  image and reads a single file you pick — the Photos library is never
  touched.
- **Finder extension** — a read-only right-click that hands the current Finder
  selection to CoreTend and does nothing else.
- **Status widget** (WidgetKit) — small and medium, aggregate figures only
  (free space, trend in words, last scan) — no paths, no private metadata.
- **Shortcuts / App Intents** — read-only actions discoverable in the
  Shortcuts app.
- **Scheduled scans & local notifications** — off by default; the only
  options are Off, Daily and Weekly. A scheduled scan is read-only and never
  cleans, deletes, or moves anything to the Trash on its own.
- **French / English** — the full UI, including locale-correct size
  formatting (`3,9 Go` / `3.9 GB`), switchable in Settings.

## Safety & privacy

Scanning is read-only. Cleanup, Duplicates, Applications, Leftovers, Privacy
Cleaner, Space Lens and Recovery Plan each show the reviewed selection and
require an explicit confirmation before eligible items move to the macOS
Trash. Every approved path is re-validated immediately before execution;
system roots are protected and symlink escapes are rejected. CoreTend does
**not** empty the Trash and has no permanent-delete path in the normal flow.

Integrity is a read-only inspection of download provenance, code-signature
tier and login items — it is **not** an antivirus or a malware scanner.

The only network request the product makes is a user-initiated check of the
public update manifest; it never downloads or installs anything. No telemetry,
no analytics, no account. The whole app works offline.

## Integrations

Finder extension, WidgetKit status widget, App Intents / Shortcuts, and local
notifications for scheduled scans are all present in this build. Enabling the
Finder extension (System Settings), adding the widget from the gallery, and
the Shortcuts listing are on-device steps.

## Known beta limitations

- **Unsigned and not notarized.** This beta has no Developer ID signature and
  no notarization ticket, so Gatekeeper blocks it on first launch. Open it the
  first time with right-click → Open (see
  `Documentation/INSTALL_UNSIGNED.md`). Do not disable Gatekeeper globally or
  strip quarantine recursively. The stable 1.0.0 line remains signed and
  notarized.
- **Beta channel.** Install this build manually. Users on the default `stable`
  update channel are not prompted to move to it; opt in under
  Settings → Updates to be offered future betas.
- **First verticals.** Recovery Plan, Storage Timeline and Developer Center
  are deliberate first slices, not their final scope.
- **Localization.** English and French are complete; other locales are future
  work.

## Not in CoreTend

No antivirus or malware scanning. No automatic or irreversible cleanup. No
APFS snapshot management or deletion. No Docker or iOS Simulator cleanup. No
Launch Items modification. No binary thinning. No image-metadata stripping
(Privacy Lab is read-only).

## Verify (once published, unsigned beta)

```
shasum -a 256 -c SHA256SUMS
```

The unsigned beta carries no staple and no Developer ID signature to validate;
`spctl` will report it as unsigned, which is expected for this build.
