# MacCare Local 0.8.0 (préversion) — Achèvement fonctionnel

Clôture tous les points automatisables du plan d'achèvement fonctionnel en
21 étapes (`Documentation/FUNCTIONAL_COMPLETION_EXECUTION_PLAN.md`).
Cycle fonctionnalités + fiabilisation — pas encore de renommage ; cette
version a été publiée sous le nom MacCare Local, toujours entièrement
local. Le renommage en CoreTend est arrivé en 0.8.1.

## Changements depuis la 0.7.1

- **Nettoyage finalisé** à 10 règles intégrées (caches utilisateur, logs,
  rapports de plantage, DerivedData Xcode, téléchargements incomplets,
  support d'appareil Xcode, sauvegardes iOS, anciens installateurs,
  anciennes archives, archives Xcode) — toutes dans le domaine utilisateur,
  toutes via la Corbeille. Quatre candidates (données Simulator iOS,
  vidage de la Corbeille, pièces jointes Mail, LaunchAgents cassés) n'ont
  délibérément **pas** été livrées comme règles d'extension/âge aveugles ;
  chacune nécessite un moteur de sécurité dédié et est documentée avec sa
  justification dans `Documentation/REQUIREMENTS_DECISION_HISTORY.md`.
- **La surveillance FSEvents optionnelle de Protection** a vu sa matrice
  de scénarios complétée : événement unique, regroupement de rafales,
  fichiers multiples, fichiers temporaires, suppression avant analyse,
  fichiers instables/en croissance, volumes démontés, ClamAV absent,
  déduplication, annulation, désactivation, persistance au redémarrage,
  indépendance au renommage, et limitation de fréquence. Désactivée par
  défaut, ne met jamais en quarantaine automatiquement.
- **My Clutter** (Volumineux & anciens, Doublons, Images similaires) gagne
  la recherche par nom, une réelle prise en compte des volumes
  (identifiant stable par volume, jamais le nom affiché que deux disques
  différents peuvent partager), et des exclusions accessibles depuis
  l'interface — le tout via la même liste d'exclusions déjà gérée par
  Réglages, pas un second système.
- **Space Lens** et **Cloud Cleanup** : travail de testabilité (logique de
  navigation, détection de fournisseurs, classification d'état de
  synchronisation) désormais couvert par des tests à base de fixtures.
- **Audit de compatibilité macOS** : chaque API utilisée se situe au
  niveau ou en dessous du seuil macOS 14.0 ; aucune protection
  `@available` nécessaire.
- **9 scénarios de stress synthétiques** couvrant de grands ensembles de
  résultats, des lots de doublons au pire cas, des arborescences larges/
  profondes, un historique SQLite à grande échelle, et des rafales
  FSEvents — aucun bug trouvé.
- **Audit d'accessibilité au niveau du code** sur toutes les vues
  SwiftUI : contrôles étiquetés, signaux d'alerte non basés sur la seule
  couleur, résumé du treemap pour VoiceOver, icônes décoratives masquées.
- **Assistant de première configuration en 8 étapes**, relançable depuis
  Réglages, avec logique pure testée (invariant de sécurité du profil,
  détection de l'emplacement de lancement, auto-diagnostic système,
  analyse de version ClamAV).
- **Dernier avertissement de concurrence Sendable corrigé** — les builds
  Debug et Release n'affichent plus aucun avertissement du projet.
- Documentation entièrement synchronisée avec le périmètre réellement
  livré : 7 nouveaux documents par module, corrections de la feuille de
  route/matrice de fonctionnalités, historique de décision documenté pour
  chaque fonction différée pour raison de sécurité.

215 → 250 tests, 0 échec, 0 avertissement de build.

**Les versions pré-1.0 sont actuellement distribuées sans signature
Developer ID et sans notarisation Apple.** Pas encore de publication
GitHub publique — voir `Documentation/HUMAN_BLOCKERS.md`.

## Limitations connues

- Non signé, non notarié : Gatekeeper bloquera le premier lancement (voir
  `Documentation/INSTALL_UNSIGNED.md`).
- Construit et testé sur un seul Mac physique (macOS 26.5.1, arm64) —
  aucune vérification multi-OS ou multi-matériel effectuée.
- La vérification interactive VoiceOver et une campagne complète de
  captures d'écran FR/EN × clair/sombre × tous les modules ne sont pas
  faites — un vrai écran est disponible dans l'environnement où cette
  version a été construite et une capture de vérification a réussi, mais
  la campagne complète reste un travail séparé
  (`Documentation/VISUAL_QA.md`, `KNOWN_LIMITATIONS.md`).
- Aucune publication GitHub publique n'existe encore ; ce manifeste n'a
  pas d'URL de téléchargement.
