# Demo Storyboard

## Product tour — capture pending

- Objective: orient a first-time visitor without implying a scan result.
- Feature: navigation across shipped 0.9.0 modules.
- Duration: 12–20 seconds target.
- Initial state: Smart Care, isolated empty store.
- Actions: select Cleanup, Performance, Applications, return to Smart Care.
- Result: viewer understands the sidebar and the different tool categories.
- Text: only the application's real localized interface.
- Dimensions: capture Retina, export 1440 px wide at 24 fps.
- Formats: VP9 WebM and H.264 MP4; silent.
- Weight: target below 1 MB per web export.
- Site: home and demos page.
- Fallback: `product-tour-poster.webp`.
- Description: provided adjacent to the player.
- Validation: must be recorded again in the dedicated CoreTend Demo account.

The earlier 10.8-second app-only recording is rejected and removed. It is not
an approved source, fallback or proof.

## Installation walkthrough — prepared, capture pending

Record in one isolated human session from the public DMG: official site,
download page, DMG download, mounted volume, copy to Applications, real first
Gatekeeper block, the version-specific per-app opening route, onboarding,
Smart Care idle screen, quit and relaunch. Do not show the operator's browser
profile, Dock, Finder favorites or desktop. Target 60–90 seconds plus a
20-second excerpt. Capture macOS wording verbatim and identify the tested OS.

This video is not generated from mockups. It remains pending because the real
dialog was observed on the current account but the only available full-screen
recording exposed private background content and was rejected.

## Feature media decisions

Smart Care, Cleanup, Performance and Applications benefit from the existing
navigation clip. Space Lens, My Clutter, Protection and Settings are clearer as
static images until neutral deterministic scan fixtures exist. Cloud Cleanup
and My Activity remain static; animation would add motion without information.
