# Asset Provenance

Inventory of non-code creative assets and their origin, for CC-BY-4.0
compliance and to catch anything that shouldn't be redistributed.

| Asset | Location | Origin | License / status |
|---|---|---|---|
| App icon (Core Bloom, 16–1024px .icns) | `Resources/` | Generated in-repo from vector/CoreGraphics code authored for this project (per Documentation/ASSET_PIPELINE.md) | Original work, CC-BY-4.0 |

| Menu bar template icon | `Resources/` | Generated in-repo | Original work, CC-BY-4.0 |
| Screenshots (Before/After) | `Documentation/VisualAudit/` | Captured from the app itself via `Scripts/capture.sh` where available; most "After" captures are pending because this sandbox has no attached display (see KNOWN_LIMITATIONS.md) | Original work, CC-BY-4.0; incomplete set is a known, documented gap, not a provenance problem |
| Fonts | None bundled — UI uses the system font (SF Pro via SwiftUI defaults) | Apple system font, not redistributed | N/A — not shipped in repo |

## Conclusion
No third-party stock imagery, icon packs, or fonts were found bundled in
the repository. All visual assets were generated by project code
(`Documentation/ASSET_PIPELINE.md`) rather than imported from an external
source, so there is no known licensing conflict. The open item is
completeness (missing "After" screenshots), not provenance.
