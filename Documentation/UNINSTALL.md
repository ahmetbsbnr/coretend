# UNINSTALL
1. Quitter l'app (y compris l'icône barre de menus → Quit).
2. Supprimer /Applications/MacCare Local.app (ou l'emplacement choisi).
3. Supprimer ~/Library/Application Support/MacCareLocal (base SQLite + quarantaine).
4. Supprimer les préférences: ~/Library/Preferences/local.maccare.app.plist si présent.
Aucun agent, daemon, helper ou fichier caché n'est installé ailleurs.
