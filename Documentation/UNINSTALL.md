# UNINSTALL
1. Quitter l'app (y compris l'icône barre de menus → Quit).
2. Supprimer /Applications/CoreTend.app (ou l'emplacement choisi).
3. Supprimer ~/Library/Application Support/CoreTend (base SQLite + quarantaine).
4. Supprimer les préférences: ~/Library/Preferences/com.ahmetbsbnr.coretend.plist si présent.
Aucun agent, daemon, helper ou fichier caché n'est installé ailleurs.
