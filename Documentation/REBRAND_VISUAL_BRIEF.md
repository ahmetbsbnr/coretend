# Rebrand Visual Brief

No final logo is produced under the name "MacClear" or any other name
this phase — `BRAND_NAME_CLEARANCE.md`'s `CONFLICT_HIGH` verdict blocks
that per the phase's own non-negotiable rule. This brief preserves what
must carry forward regardless of which name is eventually approved.

## Conceptual heritage to preserve

- **Core Bloom**: the central hero mark — a core/nucleus shape with
  asymmetric arcs, used as the app icon foundation, the onboarding static
  mark (`CoreBloomMark`), and the animated hero state in Smart Care
  (`MCHeroCoreView`, deriving visual state from real scan phase, never a
  decorative loop).
- **Orbital Ecology**: the functional color system — four hues
  (`core-mint`/`ion-violet`/`solar-amber`/`pulse-coral`, per
  `cross-site-design-tokens.json`) mapped to functional categories
  (storage/cleanup, smart-care/intelligence, protection, performance).
  This mapping is a real information-carrying system, not decoration —
  any future logo/brand system must keep colors tied to what they mean,
  not reassign them arbitrarily for aesthetic reasons.
- **Storage** (Space Lens / My Clutter), **Protection** (malware
  scanning, FSEvents watch), **Performance** (system metrics) — the three
  functional pillars the visual system already encodes via Orbital
  Ecology's hue mapping. A new name/logo must still make sense against
  these three pillars; it should not require inventing a fourth pillar or
  contradicting the existing three.

## What a new logo must NOT do

- Must not reuse or closely imitate any existing "MacClear"/"macclear"
  project's visual identity (none of the three conflicts found in
  `BRAND_SEARCH_EVIDENCE.md` had a distinctive visual mark this session
  observed, but the principle holds regardless — distinct name requires a
  distinct mark, not just a distinct wordmark next to a copied icon
  style).
- Must not imitate platform-vendor marks, system-setting iconography, or the
  distinctive identity of another utility.
- Must not imply an approval, partnership, or origin that does not exist.
- Must not use `®` (no name has reached trademark registration; using the
  symbol would be false).
