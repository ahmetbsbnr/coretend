## What's still required before any of these can be used

Same rule as MacClear: even a `LOW` risk read here is **not**
`CLEAR_FOR_ENGINEERING`. Before committing to any of these five (or a
sixth choice not on this list):

1. A real trademark clearance search (the official-registry searches this
   session could not complete — see `BRAND_NAME_CLEARANCE.md`'s
   tool-limitation note) covering at least classes 9 and 42.
2. A domain availability check via an actual registrar/WHOIS lookup (this
   session only checked DNS resolution and a couple of `.com`/`.shop`
   spot-checks — not the full set the phase brief asked for).
3. A GitHub-handle availability check for the chosen name specifically.
4. `Configuration/BrandRenameApproval.local.json` created locally with the
   user's actual choice, `approvedByHuman: true`, and
   `legalReviewStatus: "accepted"`.

Until all four hold for a specific name, that name's status stays
`BLOCKED_HUMAN` — the same as MacClear's status stays `CONFLICT_HIGH`.
