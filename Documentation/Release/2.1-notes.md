# CoreTend 2.1

**See what fills your Mac. Clear it safely.**

- Four spaces: Home, Space, Clean, Apps.
- Full Disk Access, asked once: your whole Mac in one click.
- Clean reads 14 rules at once (Xcode, simulators, npm, pnpm, Gradle, Cargo, Mail…), safe items
  ticked, and Undo puts everything back.
- Apps uninstall completely: the app and the files it left.
- Signed automatic updates, if you allow them.
- `coretend clean` and `coretend mcp` (read-only MCP server) — `npx coretend mcp`.

Everything still goes to the Trash; nothing is erased; no telemetry.

**Install:** open the DMG and move CoreTend to Applications, or `brew install --cask ahmetbsbnr/coretend/coretend`.
From 2.0: download once (or `brew upgrade`); later versions update themselves.

macOS 14 or later, Apple silicon. Signed with Developer ID and notarized by Apple.
