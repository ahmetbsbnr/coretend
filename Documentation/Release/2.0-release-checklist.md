État au 28-09-2026, après le retest du mainteneur (« tous les tests fonctionnent parfaitement »,
build notarisé 2.0.0-beta.1 sur son Mac et le MacBook Air M5).

Faits vérifiés : `main` (1.0.2 publiée) est un ancêtre de `next` → la fusion est une avance
