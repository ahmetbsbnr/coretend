**separate** Xcode lane produces the shipping bundle only.

  as a generated artifact). `Scripts/repository-doctor.sh` regenerates it
  and fails on drift, and greps for absolute `/Users/` paths.

  `main.swift` → `CoreTendApp.main()`), links the `CoreTendApp` package

  `com.ahmetbsbnr.coretend`, deployment target macOS 14.0, hardened runtime.
- `CoreTendWidget` target = `app-extension`, bundle id
  `com.ahmetbsbnr.coretend.widget`, links **only** `WidgetShared`, embedded
  in the host.
- Shared scheme `CoreTend-App` tracked. `xcuserdata` / user schemes /
  `*.xcuserstate` / DerivedData / workspace check files gitignored
  (`.gitignore` updated; `CoreTend.xcodeproj` itself is NOT ignored).

  temp derived data. Builds Release, then verifies: widget embedded at

  present with ≥ 7 App Intents + ≥ 6 App Shortcuts, no absolute path in

### App Intents metadata packaging — now proven

### WidgetKit (read-only)
- New `WidgetShared` SwiftPM target (`Sources/WidgetShared/`, + product):
  - `WidgetSnapshot.swift` — `Codable`/`Sendable`, `schemaVersion` = 1,
    `staleAfter` = 7 d, `isStale(now:)`.
  - `WidgetSnapshotStore.swift` — App Group id
    `group.com.ahmetbsbnr.coretend`, file `widget-snapshot.v1.json`.
    Atomic write (`Data.write(options:[.atomic])`). `read()` →
    `ReadResult.snapshot | .unavailable(reason:)` with reasons
    `appGroupUnavailable / fileMissing / unreadable / malformed /
    unsupportedFutureVersion`. JSON date strategy `.secondsSince1970`.
  - `WidgetSnapshotDisplay.swift` — `WidgetDisplayModel` (placeholder /
    primary / headline / detail / footnote / isStale / accessibilityLabel).
    Trend is stated in words (`widget.trend.increased/decreased/no_change/
    no_history`), never colour/arrow only. Placeholder text never contains
    "0". `WL(_:)` resolves against `Bundle.module`.
  - `Resources/{Base,fr}.lproj/Localizable.strings` — ~20 keys, EN + FR
    exact parity, **UTF-16** (repo `.gitattributes` enforces it for
    `*.strings`).
- `Sources/CoreTendApp/WidgetPublisher.swift` — `WidgetReloading` protocol +
  `SystemWidgetReloader`; `WidgetPublisher.snapshot(...)` (pure) and
  `gatherAndPublish(store:...)` (reads `latestTimelineSnapshot`,
  `latestTimelineComparisonAcrossScopes`, `activity(limit:1)` → derives the
  snapshot → atomic write → `reload()`).
- `Sources/CoreTendApp/AppEnvironment.swift` — `publishWidgetSnapshot()` /
  `publishWidgetSnapshotNow()`; called from `record(_:)`,
  `recordTimelineSnapshot(...)`. (`_ = try? await …` to keep 0 warnings.)
- `Sources/CoreTendApp/MacIntegrations.swift` — publish on `start()` and on a
  completed scheduled scan. `RestoreCenterView.swift` — publish after a
  restore that changed the summary (`restoredCount > 0`).
- `WidgetExtension/CoreTendWidget.swift` — `@main WidgetBundle`,
  `CoreTendStatusWidget` (`StaticConfiguration`, kind `CoreTendStatusWidget`,
  `.systemSmall` + `.systemMedium`), `StatusProvider: TimelineProvider`
  (reads one snapshot, `Timeline(policy: .after(+1h))`). Imports ONLY
  `WidgetKit`, `SwiftUI`, `WidgetShared`. `WidgetExtension/Info.plist` —
  `com.apple.widgetkit-extension`.

### Signing
- `Scripts/sign-and-notarize.sh` — input is now `build/CoreTend.app` from
  `build-xcode.sh` (preflight fails without the `.appex` / `Metadata.appintents`).
  Signs loose Mach-O (excluding the two bundle executables) → `.appex` with
  its entitlements → host `.app` with host entitlements → verifies both +
  re-checks the appex App Group. The appex is never re-signed after the host
  seals over it.
