# Support

## Using CoreTend

Start with [Documentation/USER_GUIDE.md](Documentation/USER_GUIDE.md), then
[Documentation/TROUBLESHOOTING.md](Documentation/TROUBLESHOOTING.md) and
[Documentation/FAQ.md](Documentation/FAQ.md).

## Reporting a bug

Open an issue using the templates in `.github/ISSUE_TEMPLATE/`. Include
your CoreTend version, macOS version, Apple Silicon model, steps to
reproduce, and expected vs. actual result. Attach only anonymized logs —
never attach files containing personal data; the templates ask you to
confirm this explicitly.

## Reporting a security vulnerability

Do **not** open a public issue. Follow [SECURITY.md](SECURITY.md) instead.

## Asking a question / requesting a feature

Use the feature-request issue template, or check
[Documentation/GOOD_FIRST_ISSUES.md](Documentation/GOOD_FIRST_ISSUES.md)
if you're looking for something to work on.

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) and [DEVELOPMENT.md](DEVELOPMENT.md).

## What support does not include

There is no paid support tier, no SLA, and no private support channel —
this is a community open source project. Response times are
best-effort.
