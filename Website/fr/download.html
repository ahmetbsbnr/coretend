Recommandé : DMG

Le DMG offre une installation claire par glisser-déposer vers Applications. Le ZIP contient la même application et reste une alternative pour les utilisateurs expérimentés. Aucun format ne change le statut non signé et non notarisé.

Installer CoreTend étape par étape

Installer une application non signée

macOS refusera d'ouvrir CoreTend au premier lancement, en indiquant que le développeur ne peut pas être vérifié. Cet avertissement est exact : aucune identité de développeur n'est attachée, car la signature exige une adhésion payante au Apple Developer Program dont ce projet ne dispose pas.

  1. Vérifiez l'empreinte SHA-256 par rapport à la valeur publiée (shasum -a 256 <fichier>).
  2. Décompressez et déplacez CoreTend.app dans /Applications.
  3. Faites un clic droit (ou Contrôle-clic) sur l'application et choisissez Ouvrir, puis confirmez. Une seule fois suffit : macOS retient la décision pour cette copie.
  4. Accordez l'accès complet au disque pour une analyse à couverture complète (voir la Documentation).

Ne désactivez pas Gatekeeper. L'étape par application ci-dessus suffit, et désactiver une protection système entière pour une seule application n'est pas un échange raisonnable.

La compilation depuis les sources est documentée dans la Documentation.
