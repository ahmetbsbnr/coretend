Installation

La version publique est honnête sur Gatekeeper.

Le téléchargement actuel n’est pas signé ni notarié. macOS bloque le premier lancement tant que la signature Developer ID n’est pas disponible ; la somme de contrôle vérifie tout de même le fichier reçu.

FAQ

Reponses courtes avant telechargement.

Envoie-t-il les noms de fichiers ?

Non. L'app fonctionne localement et le site n'a aucune analytique.

Est-ce un antivirus ?

Non. Integrity affiche provenance macOS, signatures et elements de lancement ; il ne revendique pas de detection malware.

Puis-je annuler les retraits ?

Les retraits utilisent la Corbeille systeme : la recuperation suit le flux macOS normal tant qu'elle n'est pas videe.

Pourquoi l'alerte au lancement ?

La version publique est signee ad hoc et non notarisee. La signature Developer ID reste en attente.
