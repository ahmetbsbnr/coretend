Installer CoreTend

Du téléchargement à la première analyse sans réduire globalement la sécurité du Mac.

CoreTend 0.9.0 n'est ni signé ni notarisé. macOS bloquera la première ouverture normale. Les étapes ci-dessous autorisent uniquement cette copie de CoreTend.

  1. Vérifier la compatibilité

    Menu Pomme → À propos de ce Mac. La version disponible exige une puce Apple et macOS 14 ou ultérieur.

  2. Télécharger le DMG

    Choisissez le DMG sur la page Télécharger. Le ZIP est une alternative.

  3. Copier vers Applications

    Ouvrez le DMG, glissez CoreTend vers Applications, puis éjectez l'image disque.

  4. Autoriser cette application une fois

    Dans Applications, Contrôle-cliquez CoreTend et choisissez Ouvrir. Si votre version de macOS propose plutôt une option nommant CoreTend dans Réglages Système → Confidentialité et sécurité, utilisez-la. Les libellés varient selon macOS.

    Pourquoi cette étape ?

    La bêta n'a pas de signature Developer ID et n'est pas notarisée. Ce choix limité à l'app n'est pas une certification. Ne désactivez jamais globalement Gatekeeper ou SIP.

  5. Commencer en simulation

    Lisez l'introduction, conservez la simulation activée et lancez Smart Care. L'analyse présente un aperçu avant toute action approuvée.

Facultatif : vérifier le téléchargement

SHA-256 confirme que le fichier est identique à celui publié. Il ne remplace ni signature ni notarisation, et la source du checksum doit elle-même être fiable.

shasum -a 256 ~/Downloads/CoreTend-0.9.0-arm64-unsigned.dmg
cd ~/Downloads
shasum -a 256 -c SHA256SUMS

Le DMG doit produire f2fbc7840ac4a5509836a495c51e72e6cfd52ef24e6cbdd792fa8404bd3f6c8d. Si la valeur diffère, supprimez le fichier, retéléchargez-le et ne l'ouvrez pas.
