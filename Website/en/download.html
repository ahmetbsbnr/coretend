Install CoreTend step by step

Installing an unsigned app

macOS will refuse to open CoreTend on first launch, saying the developer cannot be verified. That warning is correct: no developer identity is attached, because signing requires a paid Apple Developer Program membership this project does not have.

  1. Verify the SHA-256 checksum against the published value (shasum -a 256 <file>).
  2. Unzip and move CoreTend.app to /Applications.
  3. Right-click (or Control-click) the app and choose Open, then confirm. Once is enough — macOS remembers that copy.
  4. Grant Full Disk Access if you want full-coverage scanning (see the Documentation).

Do not disable Gatekeeper. The per-app step above is enough, and turning off a system-wide protection for one app is not a trade worth making.

Building from source is documented in Documentation.
