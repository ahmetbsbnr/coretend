Developer notes

Build and test locally with Swift 6 and Swift Package Manager. No runtime package dependencies are used.

Commands

Run `swift test`, `swift build --product CoreTendApp`, and `swift build --product CoreTendCLI` from the reconstruction repository. Tests create unique temporary fixtures.

Safety boundary

Do not test against a real home directory, CoreTend store, or Trash. The production Trash adapter is not called by tests. The next branch is public source. Signing, notarization, release tags, and distribution remain separate gates.

No download or public release is available.
