A calmer way to understand your Mac

CoreTend is a local-first macOS disk and system explorer. This reconstruction is an unreleased local preview.

Current work

The preview can inspect a folder selected by you, report measured file sizes, and find exact duplicate content. It never changes files during a scan.

Eight destinations

Overview, Record, Cleanup, Explore, Duplicates, Applications, Integrity, and Performance define the product scope. Most domain views remain under construction.

No download or public release is available.
