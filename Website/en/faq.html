FAQ

Does CoreTend send any data anywhere?

No. It has no telemetry, no analytics, no network calls related to its core operation. Everything runs locally.

Do I need an account?

No account, no subscription, ever.

Are deletions permanent?

By default, no — items go to the Trash so you can recover them.

Is this a full antivirus?

No. The optional Protection module is a heuristic local scan aid (via ClamAV), never a guaranteed security product.

Is CoreTend affiliated with Apple or CleanMyMac/MacPaw?

No. It is an independent open source project.
