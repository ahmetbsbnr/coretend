Support

Safe answers for installation, first launch and everyday use.

First launch

Use the graphical installation guide and authorize only CoreTend.

Permissions

CoreTend works with reduced coverage after a refusal. Settings explains what each permission unlocks and links back to System Settings.

Keyboard

Tab and Shift-Tab move focus; Return activates the primary action; Escape closes cancellable sheets; Command-Q quits.

Update

Quit the old copy, verify the new release, then replace CoreTend in Applications. Preferences and activity remain unless deliberately reset.

Uninstall

Quit CoreTend and move only CoreTend.app from Applications to the Trash. Data reset is optional.

Report a problem

Use the public issue tracker for bugs and the private security route for vulnerabilities.

Common problems

If a checksum differs, do not open the file. If macOS blocks the first open, follow the CoreTend-specific route; never disable system protections. Intel Macs and macOS versions older than 14 cannot run the published binary.

See the repository's Documentation/TROUBLESHOOTING.md for the complete symptom/cause/safe-resolution matrix.
