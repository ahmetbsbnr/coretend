Install CoreTend

From download to first scan without lowering your Mac's security settings globally.

CoreTend 0.9.0 is unsigned and not notarized. macOS will block the first normal open. The steps below authorize this copy of CoreTend only.

  1. Check compatibility

    Choose Apple menu → About This Mac. The available build requires an Apple silicon chip and macOS 14 or later.

  2. Download the DMG

    Use the DMG on the official Download page. The ZIP is an alternative.

  3. Move CoreTend to Applications

    Open the DMG, drag CoreTend to Applications, then eject the disk image.

  4. Open this app once

    In Applications, Control-click CoreTend and choose Open. If your macOS version instead presents a CoreTend-specific option in System Settings → Privacy & Security, use that option. Labels vary by macOS version.

    Why is this needed?

    The beta has no Developer ID signature and is not notarized. This per-app choice is not a security certification. Never disable Gatekeeper or SIP globally.

  5. Start with dry run

    Read the onboarding, keep dry run enabled, and start Smart Care. A scan previews findings before any approved action.

Optional: verify your download

SHA-256 confirms that your file is byte-for-byte the published file. It does not replace signing or notarization, and the checksum source must itself be trusted.

shasum -a 256 ~/Downloads/CoreTend-0.9.0-arm64-unsigned.dmg
cd ~/Downloads
shasum -a 256 -c SHA256SUMS

The DMG result must be f2fbc7840ac4a5509836a495c51e72e6cfd52ef24e6cbdd792fa8404bd3f6c8d. If it differs, delete the file, download it again, and do not open it.
