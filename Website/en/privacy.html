Local preview · unreleased

Privacy by design

CoreTend is designed to work locally. This unreleased reconstruction sends no telemetry and has no account or cloud sync.

File access

The app preview scans only a folder you select. Scans read metadata and file contents only when needed for exact duplicate hashing. A scan never writes to the selected tree.

Actions and records

File actions require review and confirmation, revalidate each target, and use macOS Trash only. Event records and manual performance samples stay local; event retention and the full export UI still need qualification.

No download or public release is available.
